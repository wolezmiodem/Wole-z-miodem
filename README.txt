AKTUALIZACJA STRONY WOLĘ Z MIODEM

Dodano baner „JUŻ TERAZ MOŻNA PŁACIĆ KARTĄ!” i słoik miodu na dole, który można klikać.

WAŻNE: kliknięcia są obecnie lokalne. GitHub Pages jest hostingiem statycznym i sam nie przechowuje wspólnego licznika dla wszystkich użytkowników. Żeby zrobić licznik globalny, trzeba skonfigurować bazę/backend (np. Supabase lub Firebase) i podłączyć go do strony. Nie umieszczaj tajnych kluczy administracyjnych w publicznym HTML.

Wgrywanie:
1. W repozytorium otwórz Code → Add file → Upload files.
2. Wybierz ten plik index.html i zatwierdź Commit changes.
3. Poczekaj kilka minut na publikację.
